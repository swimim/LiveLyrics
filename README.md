# LiveLyrics

## 소개

LiveLyrics는 현재 재생 중인 곡의 가사를 화면에 표시하는 macOS 메뉴 막대 앱입니다. 동기화 가사가 있는 곡은 재생 시점에 맞춰 현재 가사를 강조합니다. 별도 API 키 없이 사용할 수 있습니다.

## 설치

macOS 14 이상이 필요합니다.

1. [Releases](https://github.com/swimim/LiveLyrics/releases)에서 최신 `LiveLyrics.zip`을 다운로드합니다.
2. 압축을 풀고 `LiveLyrics.app`을 응용 프로그램 폴더로 옮깁니다.
3. `LiveLyrics.app`을 실행합니다.

## 사용법

1. 음악을 재생하고 화면 오른쪽의 타일을 눌러 가사 영역을 엽니다.
2. **Auto**를 켜면 가사를 찾았을 때 가사 영역이 자동으로 열립니다.
3. **Lock**을 켜면 마우스가 영역 밖으로 나가도 가사가 표시됩니다.
4. 새로고침 버튼을 누르면 재생 정보를 다시 연결하고 가사를 검색합니다. 검색 중에는 가사 영역이 자동으로 접히지 않습니다.
5. 가사 본문을 스크롤해 다른 부분을 볼 수 있습니다.
6. 빨간 버튼을 누르면 타일로 접힙니다. 타일을 위아래로 드래그하면 위치를 바꿀 수 있습니다.

앱 종료와 추가 설정은 메뉴 막대의 LiveLyrics 메뉴에서 사용할 수 있습니다.
