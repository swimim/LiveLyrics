# LiveLyrics

macOS 메뉴 막대에서 제어하는 가사 오버레이 앱입니다. 현재 재생 중인 곡의 가사를 화면에 표시합니다.

## 사용법

1. `dist/LiveLyrics.app`을 실행합니다.
2. 메뉴 막대의 따옴표 아이콘에서 **LRCLIB 연락처 등록/변경…**을 선택하고 본인의 이메일 또는 프로젝트 URL을 입력합니다. 값은 현재 macOS 사용자 계정에만 저장됩니다.
3. 음악을 재생하고 메뉴에서 **가사 표시**를 켭니다. **가사 잠금**을 켜면 포인터가 가사 영역을 벗어나도 가사가 계속 보입니다.

재생 정보는 macOS 현재 재생 항목을 사용합니다. 동기화 가사가 있는 곡은 LRCLIB에서 조회합니다.

## 다운로드

[Releases](https://github.com/swimim/LiveLyrics/releases)에서 최신 `LiveLyrics.zip`을 내려받아 압축을 풀고 `LiveLyrics.app`을 실행합니다. 앱이 열리지 않는다는 macOS 경고가 나오면 Finder에서 앱을 Control + 클릭 후 **열기**를 선택하세요. 이 앱은 현재 공증되지 않았습니다.

## 개인정보와 요구 환경

곡명, 아티스트, 앨범, 곡 길이, 등록한 연락처 및 통신 IP가 LRCLIB에 전달될 수 있습니다. 사용자 연락처는 각 macOS 계정에 따로 저장됩니다. 가사 원문은 앱에서 디스크에 저장하지 않습니다.

macOS 14 이상이 필요합니다. 빌드에는 Swift 6.0 이상과 CMake가 필요합니다. MediaRemote는 macOS 비공개 API를 사용하므로 OS 버전에 따라 동작이 달라질 수 있습니다.
